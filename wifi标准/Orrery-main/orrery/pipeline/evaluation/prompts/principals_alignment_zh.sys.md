<task>
对齐两份独立编写的语义参与方与值清单中的名字。只有当候选名字与语料名字表示同一个
形式化参与方或同一个形式化值时，才建立映射。这是 alpha 重命名，不是判断候选是否正确。
</task>

<constraints>
1. 映射必须一一对应。一个名字最多出现在一对映射中。
2. 相关的值不一定相同。算法配置不是选出的算法，输入不是它的派生结果，证书或信任锚
   也不是它认证的公钥。
3. 保持依赖类别：独立值对应独立值，派生值对应派生值。
4. 派生值和 `derived_from` 指名的全部源值必须一起映射；映射后的源值必须恰好等于语料值的
   源值。关系的密码学含义从 description 判断。
5. description 的措辞不同不妨碍名字对齐；把它作为判断值语义的证据。
6. 证据不足时不要映射。不要为了增加映射数量而硬凑。
</constraints>

<success_criteria>
每条映射都能说明：两个名字互相替换后，它们所表示的形式化值没有改变。
</success_criteria>
